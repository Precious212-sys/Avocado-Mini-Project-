# Avocado Price Range Analysis

## Overview
This project explores avocado price trends and range patterns using 
data visualization and exploratory data analysis (EDA) techniques.

## Contents
| File | Description |
|------|-------------|
| `avocado_project.ipynb` | Analysis and visualization of avocado price ranges |

## Tools & Libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib / Seaborn

## How to Run
1. Clone this repository
2. Open `avocado_project.ipynb` in Jupyter Notebook or JupyterLab
3. Run all cells in order
